# Public data provenance
ENSANUT 2018 → historical analytical construction → legacy survey-design correction → de-identified restricted analytical derivative.
Source microdata are INEC survey files; the analytical derivative preserves the historical variables, missingness, categories, rows and exact F4 weights. Some historical transformations are incompletely documented, so reproducing from the derivative is distinct from fully rebuilding it from source.
Survey design metadata are weights, strata and nested PSU membership. Opaque labels preserve these memberships. Retained attributes permit linkage to source survey records/codes, so individual data belong only in the restricted record. The public record contains code, dictionary and aggregate references.
Redistribution of the de-identified analytical derivative was authorized by INEC; supporting authorization is archived institutionally with INEC.
INEC source catalog: https://anda.inec.gob.ec/anda5/index.php/catalog/891 . No private authorization material or source mapping is included.
