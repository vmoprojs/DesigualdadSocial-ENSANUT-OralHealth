# Survey design and frozen specifications
ENSANUT 2018 used a stratified multistage probability design. Analysis uses the exact calibrated F4 expansion factor, PSU clustering and sampling strata, with nesting enabled in R survey 4.5.
Children and adolescents are survey domains. Primary RAW18805 analysis preserves all historical rows. Unique-row sensitivities preserve full-frame first-stage PSU totals using anonymous per-stratum counts and synthetic zero-contribution nonmember rows created only in memory before domain restriction. No extra participant data are exported.
Prevalence confidence intervals use a logit transformation with design degrees of freedom. Frozen final regressions use quasibinomial survey GLMs and t-based Wald intervals. Earlier backward elimination tested whole candidate terms using global design-based Wald F tests. Complete-case locks, factor references and final term sets are frozen inputs. No backward algorithm is executed by the public code.
The domain lonely-PSU adjustment follows the frozen primary policy, with its predeclared alternative reproduced as sensitivity. Exact original versus opaque-group equivalence is checked privately using a documented absolute-plus-relative numerical tolerance; this numerical equivalence does not certify disclosure protection.
